# goit-pycore-hw-06

Тема 9. Домашня робота: «Основи роботи з класами».

Система керування адресною книгою з класами `Field`, `Name`, `Phone`,
`Record` та `AddressBook`. Код і приклад використання містяться в
[main.py](main.py).

## Запуск

Потрібен Python 3.10 або новіший. Сторонніх залежностей немає.
У терміналі в папці проєкту виконайте:

```bash
python main.py
```

У Linux/macOS за потреби використовуйте `python3 main.py`.

Очікуване виведення:

```text
Contact name: John, phones: 1234567890; 5555555555
Contact name: Jane, phones: 9876543210
Contact name: John, phones: 1112223333; 5555555555
John: 5555555555
```

Наприкінці прикладу запис `Jane` видаляється з адресної книги.
Імпорт модуля не запускає демонстрацію.

## Класи та методи

| Клас | Призначення |
| --- | --- |
| `Field` | Базове поле з атрибутом `value` та методом `__str__`. |
| `Name(Field)` | Обов'язкове ім'я; порожній рядок або лише пробіли заборонені. |
| `Phone(Field)` | Номер з рівно 10 цифр від `0` до `9`. |
| `Record` | Поле `name` типу `Name` та список `phones` з об'єктів `Phone`. |
| `AddressBook(UserDict)` | Зберігання записів у `self.data` за іменами контактів. |

Методи `Record`:

- `add_phone(phone)` додає перевірений номер.
- `remove_phone(phone)` видаляє знайдений номер.
- `edit_phone(old_phone, new_phone)` змінює номер зі збереженням його позиції
  у списку та перевіркою нового значення.
- `find_phone(phone)` повертає об'єкт `Phone` або `None`, якщо номер відсутній.

Методи `AddressBook`:

- `add_record(record)` додає об'єкт `Record`; запис з тим самим ім'ям
  замінюється новим.
- `find(name)` повертає об'єкт `Record` або `None`.
- `delete(name)` видаляє та повертає запис; якщо імені немає, повертає `None`.

Імена зберігаються зі збереженням регістру, пошук виконується за точним
іменем, як у прикладі з умови. Зайві пробіли на початку й наприкінці імені
прибираються під час створення `Name`. Контакт може існувати без телефонів.
Повторні телефонні номери дозволені; `find_phone`, `remove_phone` та
`edit_phone` працюють із першим збігом.

## Валідація та помилки

Телефон передається рядком, тому початковий нуль зберігається:

```python
from main import AddressBook, Record

book = AddressBook()
record = Record("Олена")
record.add_phone("0501234567")
book.add_record(record)

record.edit_phone("0501234567", "0671234567")
print(book.find("Олена"))
record.remove_phone("0671234567")
```

Номер із літерами, пробілами, знаком `+`, неправильним числом цифр або
значення не рядкового типу спричиняє `ValueError`. Перевірка працює також
при присвоєнні `Phone.value`.

Пошук телефону повертає `None` для відсутнього номера. Спроба видалити або
змінити відсутній номер спричиняє `ValueError`. Якщо новий номер неправильний,
попередній номер залишається незмінним. Некоректне ім'я спричиняє
`ValueError`, а передавання в `add_record` об'єкта іншого класу — `TypeError`.

Згідно з умовою цього завдання реалізовано модель адресної книги та
демонстрацію її використання. Підключення до CLI-бота передбачено наступною
домашньою роботою. Дані зберігаються в пам'яті поточного запуску.
